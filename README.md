# Deep Haul Prototype

Браузерный прототип по мотивам Feed the Deep. Тёмная затопленная пещера, фонарь, конечный лут, видимая связка груза с резким перегрузом, кислород и возвращение на базу.

## Играть онлайн

**https://yaroslavkhomenko.github.io/deep-haul-game/** — GitHub Pages, пересобирается при каждом пуше в `main` (`.github/workflows/deploy.yml`: тесты → сборка → Pages). Репозиторий: https://github.com/YaroslavKhomenko/deep-haul-game. Нужны десктоп и клавиатура.

## Режимы

Общая ссылка всегда открывает **Уровень 1**: законченный прототип одного уровня на 5–10 минут первого прохождения. Длительность пока цель, её подтверждает тест с новым игроком.

Прежняя демка итерации 2 (песочница: 7 веток прокачки, существа, гарпуны, баллончики, капсула) сохранена в коде без изменений поведения. Она открывается только при локальном запуске по адресу `http://localhost:5174/?mode=sandbox`. На опубликованном сайте параметр игнорируется.

Сохранения раздельные: уровень — `deep-haul-level1-v1`, песочница — `deep-haul-save-v2`.

## Уровень 1

Цикл: исследовать → выбрать добычу → рискнуть оставшимся кислородом → вернуться → улучшиться → добраться дальше и вывезти больше.

- **Базы.** Старт — лодка на поверхности. Подстанция в средней зоне — вторая база после восстановления. Вход в зону работающей базы завершает вылазку: кислород полный, разгрузка, затем экран базы. Каждый вход обновляет последнюю безопасную точку, даже без груза.
- **Ресурсы.** Общий склад для обеих баз. Золото — из находок (обломок 3, руда 9, кристалл 24), тратится на 4 улучшения. Припасы — из ящиков снабжения (2 за ящик, ящик надо довезти), тратятся на ремонт ножа.
- **Улучшения** (3 уровня каждое): Кислород 25/35/45/60 с — 10/22/40; Буксир (норма груза) 6/9/13/17 — 12/24/40; Ласты 140/165/190/220 px/с — 15/30/50; Фонарь 70/110/160/220 px — 15/30/50.
- **Нож** лежит в западном кармане ближней зоны, до первой сети. Прочность 2, разрез — удерживать E 1.5 с, −1. При 0 нож остаётся, но не режет до ремонта (1 припас = 1 прочность, на любой работающей базе).
- **Уникальные детали** не продаются и сдаются только своему объекту. Два компонента восстанавливают подстанцию; тогда открывается решётка в её полу — единственный проход к дальней зоне. Двигатель (вес 13) нужно довезти до лодки; подстанция по пути восстанавливает кислород, двигатель остаётся в связке.
- **Конец уровня** — двигатель у лодки → экран результата: время, первая покупка, подстанция, вылазки, неудачи, «Пройти заново».
- **Провал** (кислород 0, «Вернуться на базу» в паузе, перезагрузка страницы): груз остаётся у точки провала, возврат в последнюю безопасную точку. Улучшения, разрезанные сети и подстанция сохраняются. Лут конечный.
- **Подсказки.** Строка «Цель», контекстные подсказки у находок и сетей, стрелка по проходам к ближайшей работающей базе (с двигателем — к лодке), предупреждение о кислороде по оценке времени возврата с текущим грузом.

| Действие | Клавиатура и мышь | Сенсорный экран |
| --- | --- | --- |
| Плыть | WASD или стрелки | Виртуальный стик |
| Подобрать находку | E или клик по предмету | «Взять» |
| Резать сеть | Удерживать E у сети | Удерживать «Взять» |
| Сбросить выбранную находку | 1–9 или клик по группе в связке | Касание группы в связке |
| Сбросить последнюю | Q | «Сбросить» |
| Пауза | Esc | «II» |

Исключено из уровня: существа, гарпун, баллончики и другие расходники, постоянные инструменты, патрули, экспедиции, переходы между районами, реклама и покупки.

## Запуск локально

```bash
npm install
npm run dev
```

Адрес печатает Vite (по умолчанию http://localhost:5174). Сборка: `npm run build` → `dist/`. Проверки: `npm test` (65 тестов на `node --test`), `npm run typecheck`.

## Устройство

Phaser 3.90, TypeScript 5.9, Vite 8. Выбор режима — `src/mode.ts`. Уровень целиком в `src/level/`: правила без Phaser (`rules.ts`, `route.ts`, `config.ts`, `map.ts`) покрыты тестами `tests/level-*.test.ts`. Сцены уровня — `LevelScene`, `LevelHud`, `LevelBase`. Песочница — `src/game/`, `src/ui/`, `src/config/`. Общие модули получили только необязательные параметры со старыми значениями по умолчанию.

`public/dev/autopilot.js` — скрипт для автоматических прогонов: тот же ввод, что у сенсорного стика, шаг цикла при скрытой вкладке, ускорение `A.speed`. В игру не подключён. Скрытая dev-панель — клавиша ` (обратная кавычка).

Скриншоты уровня — `screenshots/level-*.jpg`.
