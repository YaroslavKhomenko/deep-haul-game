# Deep Haul Prototype

Браузерный прототип по мотивам Feed the Deep (ТЗ v0.4 — `../Feed_the_Deep_Prototype_v0.4.md`). Тёмная затопленная пещера, фонарь как основа исследования, конечный лут, видимая связка груза и резкий перегруз, кислород и возвращение к причалу, нож с прочностью и ремонтом, постоянная прокачка по семи направлениям. Цель карты — поднять тяжёлую капсулу из глубины.

## Играть онлайн

**https://yaroslavkhomenko.github.io/deep-haul-game/** — GitHub Pages, пересобирается автоматически при каждом пуше в `main` (`.github/workflows/deploy.yml`). Репозиторий: https://github.com/YaroslavKhomenko/deep-haul-game. Нужны десктоп и клавиатура.

## Запуск локально

```bash
npm install
npm run dev
```

Открыть адрес, который напечатает Vite (по умолчанию http://localhost:5174). Production-сборка: `npm run build` → `dist/`, предпросмотр `npm run preview`.

Проверки: `npm test` (юнит-тесты ядра на `node --test`, включая валидность карты и экономику по этапам), `npm run typecheck`.

## Управление

| Действие | Клавиатура и мышь | Сенсорный экран |
| --- | --- | --- |
| Плыть | WASD или стрелки | Виртуальный стик слева |
| Подобрать находку | E или клик по предмету в радиусе 40 px | Кнопка «Взять» |
| Резать сеть (нужен найденный нож) | Удерживать E рядом с сетью | Удерживать «Взять» |
| Сбросить последний подобранный предмет | Q | Кнопка «Сбросить» |
| Использовать баллончик O2 (+8 с) | R | Кнопка «O2» |
| Выстрел гарпуном (нужно Оружие) | F или Пробел | Кнопка «Гарпун» |
| Пауза | Esc | Кнопка «II» |
| Dev-панель (скрыта) | ` (обратная кавычка) | — |

Потеря фокуса окна и скрытие вкладки ставят игру на паузу; продолжение — явной кнопкой. В паузе есть «Аварийный возврат» и «Новая игра» с подтверждением. Перезагрузка страницы во время погружения равна провалу: груз и остатки найденных припасов остаются лежать там, где был дайвер.

## Цикл игры

1. Старт в воде у причала; на чистом сохранении — короткая карточка с действиями и управлением. От светлой площадки вниз ведёт узкая шахта.
2. Под водой темно: виден только круг фонаря (70 px на старте, до 220 px с улучшениями), за стенами ничего не видно. Находки лежат у стен и в нишах. Кислород 25 с (+5 за уровень Баллона), расходуется 1:1.
3. Груз замедляет: до нормального веса по формуле ТЗ, выше — резко (1.5C → 27%, 2C → 9.5%); баннер перегруза подсказывает, что сбросит Q. Сброшенное остаётся лежать.
4. Возвращение на площадку причала (стрелка ведёт по проходам с учётом сетей): кислород полный, сдача груза с плавным переходом, затем база. Собранное больше не появляется — пещера постепенно очищается.
5. База: блоки «Ресурсы», «Снаряжение и припасы» (нож: прочность и ремонт по 4 монеты; гарпуны; баллончики) и «Постоянные улучшения» (Тяга, Баллон, Ласты, Фонарь, Инструменты, Оружие, Костюм).
6. Нож — находка в западном кармане первого хаба: режет тонкие сети (−1 прочности), толстые — после «Инструменты 1». Разрезанные сети не возвращаются. Враги — со второго хаба.

## Стек

Phaser 3.90, TypeScript 5.9, Vite 8. Баланс — `src/config/balance.ts`, карта и лут со стабильными id — `src/config/map.ts`. Чистая логика в `src/core/` (движение, груз, экономика, пачки припасов, состояние лута, навигация, видимость, сохранение) покрыта тестами в `tests/`.

Сохранение — `localStorage` (ключ `deep-haul-save-v2`): кошелёк, детали, улучшения, нож, припасы базы, состояние каждого предмета карты, разрезанные сети, снимок активного захода (для перезагрузки), капсула, статистика и журнал заходов.

`public/dev/autopilot.js` — вспомогательный скрипт для автоматических прогонов (ведёт дайвера через тот же ввод, что и сенсорный стик, шагает цикл игры при скрытой вкладке); в игру не подключён.
